Grup Anda

Pengingat & Ulang Tahun

Pantau masa berlaku dokumen, tagihan, langganan, acara, dan ulang tahun orang-orang terdekat. Pilih tanggal lewat kalender, hitung mundur berjalan otomatis.

Hutang & Piutang

Catat hutang Anda dan pinjaman yang Anda berikan ke orang lain. Total, sisa, dan bunga dihitung otomatis. Hutang bisa ditambah, dicicil, atau dilunasi kapan saja.

Sampah

Kredensial yang dihapus disimpan di sini selama 30 hari, lalu dihapus permanen. Password tidak ditampilkan di sini.

Per Nama

Cari nama, lalu klik untuk melihat apa saja yang disimpan atas nama tersebut (email, PIN ATM, dan lainnya).

Audit Keamanan

Periksa kesehatan password akun login Anda: yang lemah, dipakai ulang, terlalu pendek, atau sudah lama tidak diganti. Ketuk akun untuk langsung memperbaikinya.

Impor CSV

Pindahkan akun dari Chrome, Edge, Firefox, Bitwarden, atau Excel ke brankas ini. Kolom dikenali otomatis dari baris judul (name, url, username, password).

File CSV menyimpan password sebagai teks biasa (tidak terenkripsi). Setelah impor selesai, hapus file CSV-nya dari perangkat, termasuk dari folder Unduhan dan Sampah.

Bagikan / Cetak PDF

Buat file PDF berdesain berisi akun yang Anda pilih, lalu kirim ke teman atau keluarga lewat WhatsApp, email, dan lainnya. File dibuat langsung di perangkat ini.

Atau pilih akun tertentu saja

PDF berisi password dalam bentuk terbaca dan tidak dikunci. Kirim hanya lewat chat pribadi ke orang yang Anda percaya, lalu minta mereka menghapusnya jika sudah tidak dipakai.

Buka dengan Sidik Jari

Buka brankas dengan sidik jari (atau kunci layar) HP Anda, tanpa mengetik kata sandi utama.

Kata sandi utama tetap bisa dipakai kapan saja. Jika Anda mengganti kata sandi utama, sidik jari perlu diaktifkan ulang.

Pengaturan

Semua pengaturan aplikasi ada di satu tempat. Pilihan di sini tersimpan di perangkat ini dan langsung berlaku.

Cadangan Bangker Rahasia

Data diekspor dalam kondisi terenkripsi (AES-256). File cadangan hanya bisa dibuka dengan kata sandi utama vault ini.

Pulihkan dari file cadangan akan menggantikan seluruh data vault saat ini.

Bagikan beberapa akun saja ke teman. Teman tidak perlu tahu kata sandi utama Anda.

Kirim Akun ke Teman

Centang akun yang mau dikirim. File dienkripsi dengan sandi kiriman (bukan kata sandi utama Anda).

Beri tahu sandi ini lewat jalur terpisah (telepon/ketemu langsung), jangan di chat yang sama dengan filenya.

Terima Akun

Masukkan sandi kiriman dari teman Anda. Akun akan ditambahkan ke vault Anda, data yang sudah ada tidak ditimpa.

Pulihkan Cadangan

Gabungkan menambahkan isi cadangan ke data saat ini, tidak ada yang dihapus. Ganti menghapus semua data saat ini lalu memakai isi cadangan.

Keamanan

Atur kapan brankas terkunci sendiri dan kapan password yang disalin dihapus dari clipboard. Pengaturan ini tersimpan di perangkat ini.

Clipboard hanya bisa dihapus saat halaman ini terbuka. Jika Anda pindah ke aplikasi lain, penghapusan dilakukan begitu Anda kembali ke sini atau saat brankas dikunci. Riwayat clipboard bawaan keyboard/HP (misalnya Gboard atau Samsung) tidak bisa dihapus dari sini.
